# MSc Dissertation – Technical Materials

This repository contains the technical materials supporting the MSc dissertation.

## Repository Structure

- `output_overdetermined_updated/`
  - Source code, experimental results, summary CSV files and plots for the overdetermined problem.

- `output_underdetermined_updated/`
  - Source code, experimental results, summary CSV files and plots for the underdetermined problem.

- `output_small_matrices/`
  - Experimental results and plots for the small-matrix experiments.

- `Maragal_8/`
  - Source code, experimental results, summary data and plots for the Maragal-8 experiments.

## Source Code

The main Python scripts are located within the corresponding experiment folders.

## Results

CSV files contain experimental results and summary data, while PNG files contain generated plots.
